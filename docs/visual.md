1. 风格关键词
- 长文优先
- 克制叙事
- 浅蓝展览感
- 深蓝信息层级
- 淡黄重点标记
- 编辑化排版
- 轻量数据界面
- 低干扰动效
整体目标是让读者持续阅读文章，而不是被图表、装饰或动效打断。图表是论据，页面是阅读环境，动效只帮助理解章节和数据变化。

| 强边框 | `#71879F` | Focus、选中态、重要容器 |
色彩使用原则
浅蓝：营造整体阅读氛围
白色：承载正文与图表
深蓝：建立阅读层级和数据重点
淡黄色：只强调关键内容
灰蓝：弱化信息，不抢阅读焦点
- 不使用纯黑作为大面积背景。
- 不使用彩虹色图表。
- 不以红绿作为唯一的正负语义表达。
- 一屏内的重点颜色不超过两种。
- 淡黄色只用于“读者需要记住”的内容。
- “一屏内的重点颜色不超过两种”是视觉建议，不是硬性验收约束。

3. 字体系统
字体选择
| 内容 | 字体 | 状态 | 用途 |
|---|---|---:|---|
| 标题 | `Noto Sans SC` / `PingFang SC` | 推测 | 主标题、章节标题、小标题 |
| 正文 | `Noto Sans SC` / `PingFang SC` | 推测 | 长文主体、说明文字、引用 |
| 图表标签 | `Inter` / `IBM Plex Mono` | 推测 | 年份、数值、单位、图例、数据来源 |
| 特殊引语 | `Noto Serif SC` / `Songti SC` | 推测 | 可选，仅用于少量人物引语或结尾句 |

4. 长文排版
这是整套设计中最重要的部分。
正文宽度
正文最大宽度：680px
舒适阅读宽度：620px
长引语最大宽度：760px
大图表最大宽度：980px
全宽时间线最大宽度：1200px
正文不应铺满屏幕。图表可以比正文宽，但不能让图表左右边缘过于贴近浏览器边缘。
正文节奏
| 项目 | 建议值 |
|---|---:|
| 正文行高 | `1.8` |
| 段落间距 | `20—28px` |
| 标题至首段 | `24—32px` |
| 普通段落至图表 | `48—64px` |
| 图表至后续正文 | `32—48px` |
| 章节前留白 | `120—180px` |
| 章节标题至正文 | `32—48px` |
| 图表标题至图表 | `16—20px` |
| 图表至图注 | `12—16px` |
标题层级
H1：六大章节标题
H2：章节内的小议题
H3：图表标题、资料说明、人物小标题
例如：
H1：15.9%与达到四成空巢
H2：老年人口持续增长
H3：2016—2025年65岁及以上人口数量及占比
图表排版原则
正文提出问题
      ↓
图表给出证据
      ↓
图注解释统计口径
      ↓
正文解释图表意味着什么
每张图表至少包含：
- 图表编号
- 图表标题
- 单位
- 数据来源
- 统计口径
- 文字结论或图注

6. 动效规范
动效是阅读的节奏工具，不应成为内容本身。

段落进入视口
初始：opacity 0；translateY(12px)
结束：opacity 1；translateY(0)
时长：240ms
触发：进入视口约 15%
不要让每个段落都独立播放。建议以“连续的 2—3 个段落”为一个阅读组。

章节标题
初始：opacity 0；translateY(24px)
结束：opacity 1；translateY(0)
时长：360ms
触发：章节进入视口
章节编号可先出现，标题在 80ms 后出现。

图表进入
| 图表类型 | 动效 |
|---|---|
| 折线图 | 线条沿时间轴绘制 |
| 柱状图 | 从底部增长至目标值 |
| 时间线 | 节点依次点亮 |
| 流程图 | 路径与节点从左至右出现 |
| 词云 | 整体淡入，不随机飞入 |
| 地图 | 分区依次显色，不做缩放旋转 |
统一规则：
时长：500—800ms
仅播放一次
滚回页面时不重复播放
图表必须先显示静态结构，再完成动效

Hover 交互
| 元素 | Hover 行为 |
|---|---|
| 按钮 | 背景变深或转为淡黄色 |
| 卡片 | 上移 2px，阴影略增强 |
| 图表数据点 | 显示数值、单位、来源 |
| 章节导航 | 文字加深，显示细下划线 |
| 图表图例 | 高亮对应系列，其余系列弱化 |

prefers-reduced-motion 降级
开启“减少动态效果”时：
- 直接展示最终数值。
- 取消图表绘制动画，直接显示完成状态。
- 取消章节和段落位移动画。
- 保留 100ms 以下的按钮颜色反馈。
- 不使用滚动固定图表。

7. 移动端适配
排版
正文左右边距：20—24px
正文宽度：100%
正文大小：16—17px
正文行高：1.75—1.8
章节标题：34—40px
段间距：18—24px
图表
- 图表改为单列、全宽显示。
- 不使用左右分栏或固定侧栏。
- 图例过多时改为纵向排列。
- 年份标签可减少显示频率。
- 数据提示由 Hover 改为点击。
- 宽时间线改为纵向时间线。
- 表格改为横向可滚动，或转换为数据卡片。
动效
- 段落只使用淡入，不使用明显位移。
- 图表动画时长缩短至 350—500ms。
- 不使用 sticky 图表。
- 不自动播放重型动画。
- 低性能设备优先展示静态图表。
