# 技术文档

## 1. 项目定位
数据新闻网页版，滚动叙事。
文章为主体，图表穿插在段落之间。
文章为终版，见 docs/article.md。

## 2. 技术栈
- 框架：React + TypeScript
- 构建工具：Vite
- 样式：CSS + CSS 变量（tokens）
- 图表：ECharts
- 动效：IntersectionObserver + CSS transition
- 路由：初版为单页纵向滚动；首页封面与文章正文同页，以锚点导航，不引入 React Router
- 部署：待定，倾向于Vercel

## 3. 页面结构
- 同一页面内依次呈现：首页封面（文章标题 + 导语 + 进入按钮）与六章文章正文（图表穿插）
- 不做独立“关于”页
- 六个章节锚点以 `docs/article.md` 中的六个 `##### ` 标题为准

## 4. 滚动方案
- 首页封面：全屏滚动 1–2 屏
- 文章页：普通滚动，段落进入视口触发动画
- 不做全站全屏滚动
- 图表穿插在段落之间，不单独成 Tab

## 5. 图表方案
- 图表为配角，服务于文章
- 使用 ECharts
- 数据来自 `public/data/` 中现有的 CSV / JSON 文件
- 进入视口时播放生长动画
- hover 高亮 + tooltip
- 桌面端 hover 高亮 + tooltip；移动端点击查看数据提示
- 图表配色从 tokens.css 读取
- 图表懒加载，滚到才初始化
- 移动端 hover 改为点击

## 6. 动效方案
- 动效规范以 `docs/visual.md` 为准
- 段落：连续 2—3 段为一组，进入视口约 15% 时淡入 + 上移 12px，240ms
- 章节标题：淡入 + 上移 24px，360ms；章节编号可先出现，标题延后 80ms
- 图表：先显示静态结构，再以 500—800ms 完成对应图表动效，仅播放一次
- 支持 `prefers-reduced-motion`：直接展示最终状态，取消段落、章节、图表动效与 sticky 图表

## 7. tokens 落地
- 位置：src/styles/tokens.css
- 已在 main.tsx 引入
- 所有组件样式必须用 var(--xxx)，禁止硬编码颜色
- 图表配色从 tokens 读取

## 8. 内容范围
- 文章：终版，见 docs/article.md
- 初版严格按 `docs/content.md` 制作 5 张图表，不合并、不扩展
- 图表 03 仅做智能手机使用比例；图表 05 仅做平台行动时间线
- 仅按现有数据渲染，不补齐缺失数据，也不改文章结论
- 数据来源与单位在 UI 中统一标为“待补”

## 9. 约束
- 不硬编码颜色
- 不影响其他段落
- 移动端无横向溢出
- 每次改完 npm run build 通过
- 无控制台报错

## 10. 不做的事
- 不做数据 Tab
- 不做全站全屏滚动
- 不做登录、后台、评论
- 不做多语言
- 不做独立“关于”页、参考文献表或额外图表
