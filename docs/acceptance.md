# 验收标准

## 页面
- 单页能打开，首页封面与文章正文纵向连续呈现
- 可读完整篇文章
- 六个章节导航均能通过锚点跳转

## 文章
- 文章全文显示
- 段落排版易读
- 图表插在正确位置

## 图表
- 5 张图正常渲染
- 进入视口有动画
- hover 有 tooltip 和高亮
- 移动端可点击交互
- 配色与网站一致

## 动效
- 段落按 `visual.md` 以连续阅读组淡入上移
- 章节标题按 `visual.md` 过渡
- 移动端不卡
- prefers-reduced-motion 时关闭动画

## 移动端
- 无横向溢出
- 文字可读
- 图表正常显示
- 导航可用

## 构建
- npm run build 通过
- 无控制台报错

## 不做
- 不做数据 Tab
- 不做全站全屏滚动
- 不做独立“关于”页、参考文献表和额外图表
