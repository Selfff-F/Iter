页面结构
- 单页：专题封面与文章正文同页纵向排列。封面展示主标题、核心导语、章节预览和“开始阅读”锚点入口；其后完整呈现六个章节，正文与图表按叙事顺序交替出现。
- 不使用 React Router，不做独立“关于”页；章节跳转使用锚点。
- 六个章节锚点以 `docs/article.md` 中的六个 `##### ` 标题为唯一依据。

 导航
- 顶部固定导航：导语 / 老龄化双重现实 / 数字门槛 / 陪诊行业应运而生 / 陪诊赛道下半场 / 结尾
- 顶部细线阅读进度条：显示全文阅读比例。
- 桌面端右侧章节圆点：标记当前位置，可点击跳转。
- 移动端将章节目录收进菜单，不保留常驻侧栏。
- 不使用 Tab 作为文章主结构。
- Tab 仅用于单张图表内切换，例如：数量 / 占比、图表 / 数据表。
滚动与动效（简版）
- 导语标题、人物故事和“5小时”关键数字依次淡入。
- 动效规格以 `visual.md` 为准：段落以连续 2—3 段为一组，在进入视口约 15% 时淡入并上移 12px（240ms）；章节标题淡入并上移 24px（360ms）。
- 图表进入视口后仅播放一次：折线绘制、柱状增长、时间线节点点亮；图表动效为 500—800ms。
- 桌面端可让重点图表在相关段落阅读期间短暂固定；移动端始终采用“正文—图表—说明—正文”的单列顺序。
- 章节之间以浅蓝、白色和淡黄色的轻微背景变化区分。
- 不使用复杂视差、横向滚屏或持续自动播放；减少动态效果时按 `visual.md` 的降级规则展示。
功能清单
初版
- 单页封面与完整六章正文
- 完整六章新闻正文
- 顶部章节导航
- 阅读进度条
- 右侧章节跳转
- 严格按 `content.md` 的五张核心图表
- 图表标题、数据来源、单位和统计口径
- 图表 Hover 数值提示
- 数据说明抽屉
- 桌面端、平板端、移动端适配
- 返回顶部按钮
后续(根据需要添加或删减)
- 补齐其余文章图位（如后续另行决定）
- 图表全屏查看
- 图表与数据表切换
- 图表下载
- 时间范围筛选
- 地区数据对比
- 医院路线交互图
- “患者 / 子女 / 陪诊师”视角切换
- 字体放大、高对比度、关闭动画等适老化功能
